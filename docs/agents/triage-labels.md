# Triage labels

The skills speak in terms of five canonical triage roles. This repo uses
the canonical names verbatim, and all five already exist on
`cdprice02/turox`, so apply them rather than creating them.

| Canonical role    | Label in this repo | Meaning                                  |
| ------------------ | ------------------- | ----------------------------------------- |
| `needs-triage`    | `needs-triage`     | Maintainer needs to evaluate this issue  |
| `needs-info`      | `needs-info`       | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent`  | Fully specified, ready for an AFK agent  |
| `ready-for-human` | `ready-for-human`  | Requires human implementation            |
| `wontfix`         | `wontfix`          | Will not be actioned                     |

If the vocabulary ever diverges, edit the middle column. The left column
is what the skills say.
